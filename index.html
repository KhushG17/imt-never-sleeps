Disclaimer

This portal is still in development. It is built from schedules and lists shared by students, which don't arrive in one organised format, so a detail may occasionally be missing or out of date. If something looks wrong for you, or you have an idea that would make student life easier, please tell us through Feedback. It is built for student welfare, and every report and suggestion helps make it better for everyone.

  • This is an unofficial tool built from IMT Ghaziabad's official schedules and seating plans.
  • Schedules change. Always confirm against the latest official mail or notice board.
  • Anonymous usage counts are collected to improve the tool. Your roll number and name are never part of them.
