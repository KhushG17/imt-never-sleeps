      How this works

      The PDFs go straight from this browser to the site's GitHub repository. GitHub then reads them and updates the weekly schedule, which takes about two minutes. Your access key is only ever sent to GitHub.

      • Weekly schedule PDFs only. Student lists and course sheets are added from Khush's own computer.
      • A schedule that fails its checks is left out and reported here; nothing wrong goes live.
      • Uploading the same week again replaces it.
